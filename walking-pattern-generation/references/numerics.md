# 数値計算

## モデル契約

- LIPMではCoM高さ、重力加速度、固有時定数、ZMP定義、モデル仮定を明示する。
- 連続時間の式と離散更新式を区別し、周期を式へ暗黙に埋め込まない。
- 片脚・両脚支持とstep境界で、連続する状態と不連続を許す入力を定義する。
- world、base、support foot間の変換方向を型や名前で表す。

## 安定性と失敗

- 除算、平方根、双曲線関数、行列分解の定義域と極端な入力での挙動を確認する。
- 反復解法には収束判定、反復上限、非有限値検出、判断可能な失敗を設ける。
- 逆行列を直接求める前に線形方程式として解き、特異・悪条件を検出する。
- clampやepsilonで異常を隠さず、物理制約、数値安定化、障害回避を別の判断として扱う。

## 許容差

- `f64`を既定とし、別精度が必要なら理由と期待誤差を記録する。
- ゼロ近傍には絶対誤差、スケールが異なる非ゼロ値には相対誤差を使う。
- 許容差を緩める前に、式、更新順、初期値、座標変換、精度の差を切り分ける。
