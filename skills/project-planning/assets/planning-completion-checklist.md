# Planning Completion Checklist

- [ ] Objective, observable success, scope, and exclusions are explicit.
- [ ] Requirements have unique IDs and testable acceptance criteria.
- [ ] Design responsibilities, boundaries, failures, and decisions are recorded.
- [ ] Each Issue has an independent outcome and change boundary.
- [ ] Dependencies and Blocked conditions are explicit.
- [ ] Sources of truth are assigned without duplicated authority.
- [ ] PR topology is selected and justified.
- [ ] Each Stacked PR layer, if used, has one concern, a base, and validation.
- [ ] Layer-level and integrated testing are planned.
- [ ] Human approval boundaries are explicit.
- [ ] Requirements, Issues, PRs, and tests are traceable.
- [ ] Another session can start without conversation history.
