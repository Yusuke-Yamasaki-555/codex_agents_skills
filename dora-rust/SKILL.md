# Dora Rust

共通規則は対象リポジトリの`AGENTS.md`に従い、計算コア固有の設計には必要に応じて`$rust-robotics`も使う。

## 作業手順

1. ノード責務、入力・出力ポート、スキーマ、時刻の出所、周期を確認する。
2. Dora型と計算コアの値型を変換する境界を設計する。
3. キュー上限、遅延時の方針、終了条件、flush、再起動時の状態を決める。
4. 変換を純粋関数、通信と保存を副作用として実装する。
5. 変換テストと短時間のデータフロー統合確認を分けて行う。

## 参照資料

- ノードと通信境界を扱う場合は[node-boundaries.md](references/node-boundaries.md)を読む。
- dat/CSV、保存、描画、リアルタイムログを扱う場合は[logging.md](references/logging.md)を読む。

## 常に守る条件

- 未確定のポート名やスキーマを計算コアへ固定しない。
- 制御周期を通信、保存、描画でブロックしない。
- 名前、配列値、単位、timestampの対応を境界で検証する。
- 無制限キューや無制限リトライを設けない。
