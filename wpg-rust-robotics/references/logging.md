# ロギングと可視化

- 計算クレートから描画とファイル保存の依存を外す。
- ロガーはライブラリと薄いCLIに分け、入力から描画系列への変換を純粋関数にする。
- PNG、CSV、datの保存は副作用関数へ閉じ込める。
- ログの先頭行に列名と単位を書き、時刻と値の対応を固定する。
- サンプル時刻は制御周期と開始・終了の定義から決定し、期待件数をテストする。
- 生成物は専用ディレクトリへ出力し、原則として`.gitignore`対象にする。

## リアルタイム化

- 制御データの生成周期、受信周期、保存周期、描画周期を分離する。
- ロギングや描画で制御ループをブロックしない。
- Doraを使う場合は、制御モジュールをpublisher、独立ロガープロセスをsubscriberとする。
- 完全記録用経路と、表示用の間引き・最新値経路を必要に応じて分ける。
- キュー上限、遅延時の破棄方針、時刻の出所、終了時flushを設計時に決める。
- スキーマ未確定時は計算コアへ仮のDora型を混入させず、シリアライズ境界を交換可能にする。

描画の自動テストは数値変換とファイル生成までに留める。GUIは対象環境で短時間起動し、
初期化、描画、状態同期にエラーがないことを別途確認する。
