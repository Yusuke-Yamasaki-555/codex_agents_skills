# Planning Completion Checklist

- [ ] プロジェクトの目的が記述されている
- [ ] 対象範囲と対象外が記述されている
- [ ] 要件に識別子が付けられている
- [ ] 主要な設計が記述されている
- [ ] 対象Milestoneが作成されている
- [ ] Milestoneの完了条件が定義されている
- [ ] 実行可能なIssueへ分解されている
- [ ] 各Issueに受け入れ条件がある
- [ ] Issue間の依存関係が記録されている
- [ ] 各Issueの変更予定範囲が記録されている
- [ ] テスト方針が定義されている
- [ ] 人間の承認が必要な操作が定義されている
- [ ] 要件とIssueの対応関係が記録されている
